Day boxes: Each day is its own RTL file. Drop Day 10’s extract on box 10, Day 12 on box 12, etc. Only Col J age 0 (or blank) from that file counts for that day’s Allocation Tot / RES.

Saves go to the same server archive as Admin Push (report-sheet-data/rtl-daily + stable by-day/YYYY-MM-DD.xlsx). This browser also keeps a backup (like Admin), so after a code deploy you can click Restore browser backups instead of re-dropping every day. On Railway, mount a volume and set PERSISTENT_DATA_DIR=/data so day files survive redeploys.

Admin Push to Live only updates today’s RTL day (Riyadh) — past days stay on their day boxes. If a green day shows 0 age 0, that file has no age-0 rows — re-drop that day’s RTL extract.
