## Notes

1. **ST/NST**: ST = Saudi, NST = Non-Saudi (currently both use same rate)
2. **Default Rates**: When a car/year combination is not listed, the bank's default profit rate or interest rate is used
3. **Year-Specific Rates**: Some banks (Al-INMA, SNB, Al Jazira) have year-specific rates (2024, 2025, 2026)
4. **Flat Rates**: Some banks (Al Rajhi) use flat rates regardless of year
5. **50/50 Offers**: Al-INMA and Al Jazira have special 50/50 payment offers with different rates
6. **Admin Fees**: Al Jazira has special admin fees (0.5%) for eligible cars in 50/50 offer

---

## How to Edit

To edit these rates, update the `admin-data.json` file or use the admin dashboard interface. The format for year-specific rates is:
- `CarName_Year`: e.g., `Raize_2024`, `Urban_Cruiser_2025`
- For HEV variants: `Corolla_HEV_2025`, `Camry_HEV_2026`

For flat rates (no year), use just the car name: `Raize`, `Corolla`, etc.
