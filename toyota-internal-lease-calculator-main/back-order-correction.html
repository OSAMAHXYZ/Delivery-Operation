Validation rules
  • Column F — no duplicate values
  • Column I = Emp — row is correct (skip all checks, including duplicates)
  • Column K — must be 2026; if 2025 only allowed when product (L) = COROLLA CROSS
  • Column H Confirmed / Not_Confirmed — product rules apply:
  • LC70 → J must not be 0
  • CAMRY + suffix M (AA, BB, CC) → J must not be 0; interior Q/R/S must not be 0 or 20
  • LC300 + suffix M (G2, G3, G4) → J must not be 0
  • RAV4 — interior Q/R/S must not be 0 or 20 (except suffix SH or VH)
  • RAV4 + suffix SH — N/O/P must each be one of: 218, 2SQ, 2VP, M2L
  • YARIS SD — suffix (M) must not be BA
  • VELOZ — exterior colors N/O/P must not be S28
