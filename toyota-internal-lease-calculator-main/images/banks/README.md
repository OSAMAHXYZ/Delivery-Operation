# Bank Logos Directory

This directory contains bank logo images for display in the calculator results.

## Logo File Names

Please place your bank logo images with these exact file names:

- `al-rajhi.png` - Al Rajhi Bank
- `al-inma.png` - Al Inma Bank  
- `snb.png` - SNB Bank
- `aljf.png` - ALJF
- `al-riyad.png` - Al Riyad Bank
- `al-jazira.png` - Al Jazira Bank
- `default.png` - (Optional) Default fallback logo

## Logo Requirements

- **Format**: PNG (with transparent background preferred) or JPG
- **Size**: Recommended 200x200px to 400x400px
- **Aspect Ratio**: Square or close to square works best
- **File Size**: Keep under 200KB per logo for faster loading
- **Background**: Transparent PNG is recommended for best appearance

## Notes

- If a logo file is missing, the system will automatically display a colored circle with the bank's first letter as a placeholder
- Logos are displayed in a 100x100px container in the results cards
- The logos will automatically scale to fit while maintaining aspect ratio
